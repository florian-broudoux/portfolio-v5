# Portfolio de Florian

Mon portfolio de développeur web en formation : présentation, projets et contact.

## Technologies

- HTML et Tailwind CSS 4
- Vite 8
- Prettier et ESLint

## Installation et lancement

Il faut Node.js 24 (LTS). Dans le dossier du projet :

- `npm install` : installer les dépendances
- `npm run dev` : lancer le serveur de développement (http://localhost:5173)
- `npm run build` : construire le site dans le dossier `dist/`
